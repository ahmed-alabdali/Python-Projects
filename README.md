# File Organizer Script

A Python automation script that organizes files in a specified directory into categorized subfolders based on their file extensions.

## Features
- Automatically creates folders for Images, Documents, Videos, and Music.
- Safely moves files using the `shutil` library.
- Includes error handling for system permissions.

## How to Run
1. Run the script: `python organizer.py`
2. Enter the path of the folder you want to organize (e.g., `C:\Users\YourName\Downloads`).
