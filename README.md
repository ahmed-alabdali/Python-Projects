# Python Projects Portfolio

Welcome to my Python projects repository. This repository contains three main applications built to demonstrate my skills in Python, automation, and data handling.

---

## 1. Student Management System (main.py)

A Command-Line Interface (CLI) application designed to manage student records.

### Features
- Add new students with their names, grades, and status (Passed/Failed).
- View a list of all registered students.
- Stores data persistently using JSON files (`students.json`), ensuring data is not lost after closing the program.
- Includes error handling to validate user inputs.

### How to Run
1. Run the script: `python main.py`
2. Follow the on-screen menu to add or view students.

## 2. File Organizer Script (organizer.py)

An automation script that organizes files within a specified directory into categorized subfolders based on their file extensions.

### Features
- Automatically creates folders for Images, Documents, Videos, and Music.

## 3. Credit Card Validator Tool (credit_card.py)

A Command-line Interface (CLI) tool built with Python to verify the authenticity of credit card numbers

### Features
- Utilizes the **Luhn Algorithm** to validate card numbers.
- Strict input sanitization to remove space and hyphens.
- Includes error handling to ensure only numeric input are processed

  ### How to Run
1. Run the script: 'Python credit_card.py'
2. Enter a credit card number when prompted
